# SAE-Gestion_Projet-Instagram


le dossier comporte actuellement 5 fichiers.
Après l'avoir télécharger il faut s'assurer d'avoir node.js sur son pc.
on initialise le node "npm init -y"
On télécharge le socket "npm install express socket.io" en ligne de cmd
Une fois tout les modules télécharger on lance "npm install" et ensuite "node indexe.js"
