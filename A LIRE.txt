1. CORRECTION DU SCRIPT SQL (CRITIQUE) :
Dans le script de création de la BDD, vous avez utilisé la syntaxe MySQL (`AUTO_INCREMENT`). Mais comme notre serveur Node.js est configuré pour SQLite (dans bdd.js), le code va planter.
-> ACTION : Remplacez absolument tous les `AUTO_INCREMENT` par `AUTOINCREMENT` (sans le tiret du bas) dans la création des tables.

2. AJOUTS DES COLONNES DANS LA BDD :
Ma partie gère la sécurité (middleware admin), le masquage automatique et la suppression logique (soft-delete). 
-> ACTION : Ajoutez ces colonnes dans votre script SQL :
- Dans la table `Utilisateur` : Ajoutez -> `role VARCHAR(20) DEFAULT 'user',`
- Dans la table `Publication` : Ajoutez -> `is_hidden BOOLEAN DEFAULT 0,` et `is_deleted BOOLEAN DEFAULT 0,`

3. INTÉGRATION DANS LE SERVEUR (index.js) :
Pour que mes routes et mon tableau de bord soient accessibles, il faut les lier au serveur principal.
-> ACTION : Dans le fichier `index.js`, ajoutez ces lignes juste après vos `app.use(...)` (vers la ligne 19) :

const adminRoutes = require('./adminRoutes.js');
app.use('/api/admin', adminRoutes);
app.get('/admin', (req, res) => {
    res.sendFile(__dirname + '/admin.html');
});
